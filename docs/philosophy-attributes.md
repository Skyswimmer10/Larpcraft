# Optional philosophy and values

Characters and Groups use the existing compact **Quick attributes** button. Open **Manage attributes → Philosophy & values**, select the fields wanted, and apply. No field is mandatory.

- **Philosophy schools**: choose multiple curated schools or type custom entries. The initial list includes Absurdism, Cynicism, Ecocentrism, Existentialism, Humanism, Idealism, Nihilism, Pragmatism, Rationalism, Skepticism, Stoicism, Utilitarianism, Virtue ethics, Duty ethics, Care ethics, Hedonism, Confucianism and Daoism.
- **Ethics & guiding principle**: optional short note. Longer development can stay in frameworks and concepts.
- **Values & outlook**: optional descriptive tags, with custom entries.
- **Authority style** and **Social expectations**: optional tags and a short note, especially for Groups.

All use `node.characterAttributes.fields`, retaining the established tags/text format and custom entries. Selected values appear in the full description window, canvas attribute chips and text exports for characters and groups. They do not rewrite protected descriptions, wizard questions or answers. The regular graph/library copy, undo and workspace backup paths preserve these additive fields.

Philosophy is an authoring association, not a new node type. Opposing schools can be referenced using existing relationship descriptions, Story Beats and discussion prompts; no automatic conflict simulation is implied. Religion remains representable through Groups without a separate religion, language or system entity.
