# Kolb wizard plan

Reuse the existing React dialog, plain CSS, FATE choice/range/curve controls, scope-aware entity references, vocabulary helpers and project persistence pattern. Keep FATE's public helpers stable; expose reusable control names through a shared module. Kolb has its own cycle-aware draft and dependency rules rather than forcing turns into a four-pillar FATE draft.

- Simple and Advanced share one versioned draft; earlier answers remain visible and editable.
- Four plain-language stages, selectable entry point, up to four cycles, explicit observation-to-idea links, test branches and before/after/behaviour summaries.
- Suggestions require acceptance. No learning habits, outcomes or cognitive gains are inferred from filled fields or backstory.
- Separate planned continuations from observed outcomes. Copy an explicitly selected result into the next cycle and retain its provenance and review state.
- Advanced adds linked learners, optional habit grid, educator roles, pacing, purpose-specific notes, review mode, output formats and selective FATE imports.
- Unfinished drafts and preferences use the existing project save pipeline, separately from finished nodes. Preserve legacy phase keys and original notes.
- Verify migration, linked evidence, turn rotation, branches, stale context, locked fields, editable output, game/library insertion, local disk round-trip, and desktop/mobile browser flows. No new dependencies.
