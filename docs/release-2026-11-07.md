# LARPCraft release — 7 November 2026

Publishes the completed local work across narrative creation, reusable content and physical databases, character/group/item/location cards, conversation writing, research and media, relationships, map and canvas annotations, story planning and dynamics, framework workshops and appearance options.

Story Beats include the wide category-rail workshop, typed live participant replacements, contextual follow-ups, an internal story canvas, and the General and Character Interaction starting approaches. Follow-up questions have a separate enclosing background while their word-replacement controls retain their existing surface. The canvas pans in every direction with the middle mouse button. Created Content switches between Game and Database; only Game entries have deletion controls in that picker.

The conversation workspace includes the goal compass, editable icons, resizable side panes, per-message centering, portrait previews, message controls, line tags and PDF/screenplay export. Character creation includes optional quick attributes, media/references, character profiles and updated archetype and King/Warrior/Magician/Lover workshops. Node portraits scale alongside framework symbols.

The release captures Operation Chimera as project bundle version 5 and the master library as library bundle version 7. The project includes 12 narrative nodes, 6 mechanic graph nodes, 2 conversations and 1 relationship; the library includes 45 concepts, 10 created-content entries and 1 reusable conversation. Embedded images are externalized to content-addressed public assets. Original local project/library files were backed up under ignored `.larpcraft/releases/` and left unchanged.

Local files, credentials, environment files, dependencies, scratch files and recovery archives are excluded from publication. The hosted build remains a static application: hosted edits save in that browser and are not automatically synchronized with the local computer. Existing browser saves retain the established merge protections. File → Save complete workspace remains the portable export of the full active game and library.

Validation: full Vitest suite, production build, release-snapshot preservation tests and Git index checks before publication. The existing production bundle-size warning remains.
