# Kolb learning and discovery workshop

Open Story Wizard and choose Kolb's Learning Cycle. Simple and Advanced use the same saved answers; changing modes only changes which controls are visible.

## Simple

1. Name the version, choose what you are developing and describe the situation.
2. **Experience:** describe what happens.
3. **Reflection:** record what someone notices, with optional individual observations.
4. **Understanding:** describe the idea they form and select the observations that support it.
5. **Test:** describe what they try and optionally write possible results.
6. **What changed?:** review the earlier belief, new understanding and different behaviour, then edit the finished paragraph before saving.

You can start at any of the four stages. A selected possible result can start another cycle, up to four cycles. A possible result remains a plan until you explicitly mark it as the recorded outcome.

## Advanced

Advanced adds linked learners, optional learning habits, context and purpose-specific notes, pacing, roles, alternative results, selective FATE imports and different output formats. Review mode reports gaps in the details you enter; it does not automatically interpret a source description or measure learning.

The context rail retains earlier answers. Suggestions require a click before being used. Changing source answers flags dependent details for review without replacing your writing. Step locks and undo/redo help protect decisions.

## Saving and older work

Unfinished drafts and preferences follow the existing project save pipeline and reopen at the last stage. Autosaving a draft does not create a canvas node. Save to game writes the finished result; Save to library + game also makes a reusable library record. Full answers remain available alongside the editable prose.

Continue saved wizard imports older Kolb answers without shortening them and preserves unrelated questions and nested content. Editing a saved version updates that version in place. Copying saved work creates a separate draft.

No AI service or additional package is required. Paragraphs and suggestions are generated locally from the recorded choices.
