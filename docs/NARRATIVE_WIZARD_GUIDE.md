# Narrative wizard: choosing the right use

Reviewed 17 October 2026. These are practical writing recommendations for Larpcraft, based on the actual reference and concept content. Best fit and also useful are suggestions, not restrictions or scientific rankings. Existing library categories and authored content are unchanged.

## Main findings

- Characters: the two archetype frameworks and the fictional MMPI-2-inspired profile are strongest here. NLP Meta Programs can also help write preferences and decisions.
- Communication: FATE shapes attention, credibility, belonging, and emotion. NLP Meta Model helps unpack statements and write dialogue. Several concepts saved under Character Concept actually serve communication.
- Relationships: archetypes can illuminate roles between people; Human Values and Moral Conflicts help show competing needs, duties, and loyalties. Hero and Guide is often a relationship pattern.
- Values: Human Values makes stakes meaningful; Moral Conflicts gives different sides competing reasons to consider a choice right.
- Story arcs: Descent and Recovery and Home, Voyage, Return organise changes across events. Story Building System helps plan the purpose and construction of a story. Master Story remains the summary/timeline, not the primary writing engine.
- Learning: Kolb is strongest for experience, reflection, an idea, and another chance to act.
- Scenes and presentation: references can also help design a single encounter, a voice, or a delivery method without claiming to supply an entire story structure.

## How the wizard now works

1. Browse references by purpose. Best fits appear before other useful options; every source remains available.
2. Select what you are developing and choose a new result or an existing narrative node.
3. For concepts, replace roles if needed; the source graph and its relationships remain intact in a detached copy.
4. Answer questions that fit the selected purpose. Existing concept questions are retained alongside short starting questions for that purpose.
5. Review the result. Characters use ordinary editable character questions; other purposes save as editable plan containers with reference/answer nodes. Adding notes to an existing node preserves its type, fields, and connections.
6. Save to the game, or to both the library and game. Nested game canvases keep their scope. Answers for different purposes remain separate while the wizard is open; only the reviewed purpose is saved.

The feminine archetype reference uses Toni Wolff roles and Larpcraft adult-shadow interpretations. It does not inherit the masculine model's child forms. These references remain writing aids rather than player assessments.

## Recorded choices and connected questions

The wizard keeps choices separate from written notes. Selecting King records King while leaving room to explain what that means in this story. Later questions explicitly use fair leadership, the Divine Child, the Tyrant, and the Weakling from that reference. Relationship questions use both chosen archetypes. The feminine roles use their own strengths and adult shadows.

The same principle applies throughout the workshop:

- FATE connects attention, credibility, belonging, and feeling around the message being developed.
- Kolb builds reflection from the recorded experience, an idea from that reflection, and a test of that idea.
- Story arcs connect each stage to the stage already described.
- Values and moral conflicts ask where a new value supports or clashes with the earlier one.
- NLP preferences keep a selected preference and its explanation separately; its reference description guides development.
- NLP language patterns return to the same recorded conversation. Character profile questions develop the same fictional person across different situations.
- Concepts retain adapted roles and show earlier answers alongside later questions.

“Your recorded choices” and expandable answer lists make the writer's own words visible. “Earlier answers used here” can jump back to edit an earlier answer. Other frameworks already saved on the target are available as background; the tool does not invent new character facts from those notes.

To reopen saved answers, select the game node and use **Continue saved wizard** in the inspector. When several frameworks or concepts have been applied, choose the saved questionnaire in the setup screen. Saving updates that questionnaire in place while preserving unrelated nodes, graph layout, and links. Normal character answers and framework note nodes edited outside the wizard are read back when continuing. Alternative archetype answers are kept separately, so switching King → Warrior → King restores the King draft; saving retains those alternatives in the wizard record. Save before closing to retain new changes. Unsaved changes still have a discard confirmation.

## Meta Programs: four-step workshop

The Meta Programs framework now opens four short windows inside the existing Story Wizard:

1. **What drives them?** Motivation and information scope use five-position sliders; action uses a single choice; interests allow several choices.
2. **How do they work with others?** Decision evaluation and comparison style use choice cards. Exploring alternatives and following a method can both be selected. Optional creativity roles cover imagining, planning, and reviewing a shared task.
3. **How do they communicate?** Explanation formats can be combined, a viewpoint can be selected for the situation, and a line of dialogue makes the choices concrete. Word and voice preferences are optional.
4. **What tests or changes them?** Describe a challenge, goal, and observable response. Add any number of explicit situation changes with a trigger, changed behaviour, example, and return condition. Optional questions explore causes, resources, success, setbacks, turning points, and attention to time.

No slider position is recorded until the writer interacts with it or explicitly chooses Mixed. Choices never overwrite written explanations. Optional sections remain available without adding defaults or automatic stress flips. Old six-spectrum records retain their original choice values and notes when reopened. The normal Save to game, Save to library + game, Continue saved wizard, and saved-session selection all apply. Existing archetype work can guide the final scene test.

For character results, the review screen now presents an editable story paragraph instead of a questionnaire transcript. Recorded preferences become plain descriptions of behaviour, with the writer's background, scene details, dialogue, and active exceptions woven into the same paragraph. Unanswered traits are left out. This is a local prose formatter using recorded answers; it does not invent additional character history. Choices and answers remain under an expandable section and in the saved wizard record for continued editing. Both the game description and library copy use the paragraph.

Editing the paragraph preserves that wording when answers change. **Rebuild from answers** explicitly replaces it with a fresh paragraph after confirmation. Reopening a saved Meta Programs character wizard and saving it updates the old questionnaire description in place; unrelated character content is preserved. Other narrative purposes continue to save their existing editable plans.
