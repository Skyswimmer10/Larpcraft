# Human Values wizard plan

Implement the reviewed proposal using React, existing plain CSS, shared wizard controls, scope-aware entity helpers and `useStoryWizardDraft`. No new dependencies.

- Simple: situation, choose the values that matter, describe their states and human meaning, review editable story prose. No mandatory dilemma or loss.
- Advanced: implications, differing stakeholder interpretations, possible outcomes, information timing, choices, scene/act arcs, optional writer ratings, selective FATE/Kolb imports and review mode.
- One shared draft, project autosave, resume, undo/redo, locks, context and explicit suggestions. Retain hidden fields and custom vocabulary. Save to game or game plus library through existing insertion/revision functions.
- State tracks use named choices, not numeric distances. Importance/intensity are writer estimates; no emotion formula or summed best-choice score. Separate actual states from perceived states. Protected values and relief are valid.
- Preserve older text and choices without interpreting a selected pole as a story ending. Custom values belong to the project and may have contextual state names.
- Verify meaningful pure behavior, real API/disk persistence and isolated desktop/mobile browser flows, followed by the full suite and production build.
